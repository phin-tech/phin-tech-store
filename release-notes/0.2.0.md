The first release of the Phin Tech Store.

- Every app on apps.phin.tech, as boxed software on walnut shelves, read fresh from the
  catalog each time the store opens (and kept for when you're offline).
- A magazine ad for each app, with a clip-out order form: **Install** downloads the
  release, checks its SHA-256 and puts it in Applications; an older copy goes to the Trash.
- **Owned**, **Update** and **New!** stickers on the boxes, and **Store ▸ Update All** (⇧⌘U).
- Herdr plugins download to your Downloads folder, with their install command a click away.
- Pepper never forgets.
